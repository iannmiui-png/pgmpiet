Palette & Command Reference

Palette

Moving from one colour block to the next executes a command based on Δ = (new step − old step) mod 18 — the command depends on the difference between steps, not on either colour alone.

Commands (by Δ)

The command executed when exiting a block of size N and entering the next, for each possible Δ.
About pgmpiet paint
A paint program for pgmpiet, the grayscale derivative of Piet. Palette: black (33), white (255), and 18 grayscale steps (112…247) in canonical hue-major order. The Run panel embeds a full interpreter so you can test programs without leaving the editor.
